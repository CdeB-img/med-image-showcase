# Engine Lab Tasks

The task registry is authoritative only inside the experimental sandbox. A task directory is created only when it has an implementation, contract or immediate evidence. Existing semantic-reconstruction runners remain under `experiments/semantic-engine-comparison/`; they are referenced, not copied.

The first bounded implementation planned for this foundation is `semantic-audit/`. Semantic adjudication, clarification ranking, contextual enrichment, documentary reasoning and temporal memory remain registry entries until a bounded experiment gives each one a concrete artifact.
