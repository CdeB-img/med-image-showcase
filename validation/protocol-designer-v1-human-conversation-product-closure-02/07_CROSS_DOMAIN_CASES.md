56 régressions nouvelles réellement exécutées dans `human-conversation-product-closure-02.test.tsx` ; aucune golden string de compétence scientifique.

| Cas | Résultat démontré |
|---|---|
| Offre unique IRM M3 / questionnaire J30 / tranches d'âge → oui | Binding exact, admission à l'extraction, autorité de write false |
| Discussion T1/T2, exemple ou condition sans adoption | Pas de proposition engageable inventée |
| Deux timings alternatifs / deux offres / options numérotées → oui | Clarification ciblée |
| Oui mais / non / je refuse | Pas d'adoption intégrale |
| Ancienne proposition après refus | Aucun référent visible courant ressuscité |
| Texte, digest, source, option, candidateRef ou statut forgé | Rejet par validation sémantique existante du Bridge |
| Demandes de référence / littérature / études / équipes | Acte externe, retrieval non exécutée |
| Attribution anonyme affirmative | Rejet explicite et observable |
| Raisonnement méthodologique général, limite de vérification | Texte autorisé |
| Source identifiable fournie / citation étrangère | Acceptation de provenance identifiable / rejet de citation non disponible |
| Inputs statistiques complets / SD manquante / pertes absentes | Calcul exact / pas d'invention d'input |
| Six groupes / intervalle / unités incompatibles / puissance invalide | Pas de calcul non applicable |
| Scénario numérique modèle accepté | Provenance modèle conservée, non décision Project |
| SD « classique » / 20–25 par tranche / N non calculé | Rejet |
| Recrutement utilisateur annoncé | Rapport comme faisabilité autorisé ; affirmation de suffisance rejetée |
| Effectif natif erroné avec inputs complets | Serveur affiche le résultat déterministe, une seule tentative synthétique |

Les suites d'owners réutilisées complètent ces contrastes : décision/mixed acts, persistent delta, référentiel, PRJ, présentation review, source coverage, calcul, sessions et configuration publique. Les tests de garde sont bornés ; ils ne constituent pas un oracle de jugement humain.
