# REFERENCE-CORPUS-01 — governed reference seed

Status: `NON_NORMATIVE_REFERENCE_REGISTRY`; consumed read-only through the existing `REFERENCE-KNOWLEDGE-BRIDGE-01` runtime.

This directory records external reference material and existing NOXIA documentary assets for later owner-specific coverage analysis. It does not admit external material as NOXIA authority, extract executable rules, or modify any scientific owner.

## Reuse-first boundary

- `regulatory-funding-corpus/reg-000` supplies the existing temporal, jurisdiction and applicability conventions.
- `documentary-pattern-corpus/doc-002/documentary-source-catalog.json` supplies the existing digest/provenance boundary and the `EVIDENCE_ONLY_NOT_AUTHORITY` principle.
- `src/features/knowledge-engine` remains the existing read-only runtime consumer boundary; this expansion changes no bridge, owner, Project or QRY runtime file.
- This directory remains the single RC01 registry for raw external source identity, licence/storage status, linked-study lineage, search decisions and corpus gaps.

## Files

- `reference-corpus.json`: accepted external sources and local-copy metadata.
- `reference-corpus.schema.json`: required metadata contract.
- `linked-study-sets.json`: verified same-study artifact relationships.
- `platform-trial-reference-set.json`: bounded five-platform comparison with explicit master/domain, adaptivity, imaging, analysis, lineage and limitation fields; no pattern admission.
- `existing-noxia-assets.json`: pointers to existing assets; no duplication or authority change.
- `search-log.json`: discovery routes and dispositions.
- `rejection-log.json`: rejected and deferred candidates with reasons.
- `gap-matrix.json`: coverage by the 15 required domains.
- `targeted-gap-reclassification-01r.json`: explicit post-acquisition status of the seven prior P1 targets with need, owner, source, anchor, jurisdiction and limitation evidence.
- `validate.mjs`: read-only documentary integrity checks.
- `sources/fda/`: six unaltered FDA PDFs whose local storage and redistribution are supported by the FDA website policy; logos and marks are not separately licensed.
- `sources/eu/`: one unaltered European Commission CTR Q&A PDF retained under the Commission site reuse policy; MDCG documents remain metadata-only because hosting was not treated as proof of file ownership.

## Epistemic boundary

`OWNER_RELEVANCE` means potentially useful to an existing owner. It never means owned by, adopted by, or executable by that owner. `RETRIEVAL_QUALITY_TIER` describes source/retrieval quality, not scientific validity. Applicability is recorded on four separate axes and is never collapsed into a score.

Corpus content is exposed only as source snapshots and bounded evidence candidates through the existing bridge. Registry presence still never authorizes a Project write, owner decision, scientific claim or generic practice rule.
